# 刻页 · 方案 C 实现说明

品牌与组件依据 `01_品牌Logo_方案C.png`、`02_UI组件板_方案C.png` 及两份独立 Logo PNG。产品界面、扩展名称、标题和文件默认名称统一使用「刻页」。

- 五段声波标识以 `extension/brand/mark.svg` 和 `mark-white.svg` 提供矢量实现，保留原始 PNG 的形状比例；扩展图标由同一矢量标识生成 16 / 32 / 48 / 128px PNG。
- 公共设计变量位于 `extension/style.css`：背景 `#151719`、面板 `#1C1E21`、表面 `#25282B`、边框 `#303236`、强调色 `#B2EF83`、播放位置 `#F0B078`、录制 / 错误 `#F46A66`。
- 按钮高度 28–32px，主要间距采用 4 / 8 / 12 / 16px；保持紧凑、按窗口宽高自适应的现有工作台结构。
- 组件覆盖默认、悬停、按下、禁用、键盘焦点、输入错误、录制、暂停、导出、完成和失败状态；状态同时使用文字和图形表达。
- 录制弹窗与编辑器共用设计变量；图标悬停和键盘聚焦使用带边框的提示，提示不会改变界面布局。
- 原始 UI 图片作为视觉规范保留；界面与组件使用 HTML / CSS / SVG 实现，不依赖整张规范图作为背景。

录制历史数据库名称保持原值，避免更名后无法访问已有录制。
